# Ostrin Brand Guide

This is the initial, practical brand guide for Ostrin. It is intentionally
small and should keep the identity consistent while the language evolves.

## Identity

- **Name:** Ostrin
- **Wordmark:** `OSTRIN`, uppercase when used as a visual mark.
- **Tone:** precise, calm, technical, readable and exploratory.
- **Positioning:** a programming language built from first principles, with
  physical quantities and safe-by-default concurrency as distinctive ideas.

## Official mark

The official mark is the geometric white-and-violet symbol on a dark navy
background:

## Colors

| Role | Hex | Use |
|---|---|---|
| Ink | `#070910` | Main dark background and logo field |
| Violet | `#5B3DF5` | Primary accent and calls to action |
| Electric violet | `#7C5CFF` | Highlights and interactive states |
| Lavender | `#C8C4FF` | Soft accent on dark surfaces |
| Snow | `#F7F8FF` | Primary text and light mark |
| Muted text | `#A6A9BC` | Secondary text on dark surfaces |

## Typography

- Wordmark: a bold geometric sans-serif, uppercase, with modest letter
  spacing.
- Product UI and website: `Inter`, `ui-sans-serif`, `system-ui`, sans-serif.
- Code: `JetBrains Mono`, `Cascadia Code`, `Consolas`, monospace.

## Usage rules

- Preserve the symbol's proportions and clear space.
- Prefer the official dark-background mark on dark or neutral surfaces.
- Do not stretch, rotate, outline, recolor or add effects to the symbol.
- Do not place text inside the symbol.
- Use the wordmark `OSTRIN` beside the symbol when the project name needs to
  be explicit.
- The source-file extension is `.ostrin` in code and documentation.

## Product surfaces

The same identity should appear in the GitHub repository and social preview,
GitHub Pages site, VS Code extension, compiler and future application icons,
documentation and examples.
