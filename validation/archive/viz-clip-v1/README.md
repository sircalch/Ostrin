# Archived Viz evidence: clip id v1

Copies of the generated Viz outputs made immediately before the `clipPath` identity change in
`compiler/std/viz.ostrin` (the clip id was derived from title, labels and series count only).

- `experiments/`: the 30 `ostrin.experiment/v0` bundles with the old recorded SVG hashes.
- `assets/viz/`: the 33 published Viz SVG assets as they were.
- `lab-data.js`: the gallery data file that recorded those assets.

These files are evidence for the v1 renderer. They are not replayed by current tooling. The current
outputs are the regenerated bundles and assets under `website/`. Git history also contains these files.
