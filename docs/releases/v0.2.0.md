# Ostrin v0.2.0 — Experimental release

Ostrin v0.2.0 is an experimental 0.x release of the `ostrinc` compiler and
scientific computing toolchain. It is intended for evaluation and feedback; it
is not production-ready. The 0.x compatibility policy permits syntax,
diagnostic and API changes.

## Supported platforms

The release workflow builds each archive from the exact `v0.2.0` tag and
attaches SHA-256 checksums.

| Platform | Release asset |
| --- | --- |
| Linux x86_64 (glibc) | `ostrinc-v0.2.0-x86_64-unknown-linux-gnu.tar.gz` |
| macOS ARM64 (Apple silicon) | `ostrinc-v0.2.0-aarch64-apple-darwin.tar.gz` |
| Windows x64 | `ostrinc-v0.2.0-x86_64-pc-windows-msvc.zip` |
| WASI Preview 1 | `ostrinc-v0.2.0-wasm32-wasip1.tar.gz` |

Native archives include the compiler, license, README and runnable examples.
The WASI archive includes the compiler module, the 28-program smoke matrix,
`SHA256SUMS` for all WebAssembly modules, and a README. The supported WASI host
must provide Preview 1 and WebAssembly exception handling for cooperative
task cancellation.

## Install

Use the repository installer with an explicit version and verify the attached
checksum before running the compiler:

```sh
scripts/install.sh --version 0.2.0
ostrinc --version
ostrinc --check examples/hello.ostrin
ostrinc --run examples/hello.ostrin
```

On Windows PowerShell, use `scripts/install.ps1 -Version 0.2.0`. For WASI,
download the WASI release asset, verify its archive checksum and then verify
each module with `sha256sum --check SHA256SUMS` after extraction.

## Included capabilities

- A measured native backend with 7,198 IR and 41 HIR bodies and zero AST
  fallbacks in the recorded corpus. This count does not imply native support
  for every valid source shape.
- Ownership evidence for the tested combinations in
  [`docs/ownership-matrix.md`](../ownership-matrix.md).
- Scalar `Measurement<Float>` support in the documented tested contexts.
- Numerical validation for LU, Cholesky, QR, SVD and symmetric eigenpairs,
  using analytic cases, residuals and declared tolerances.
- Scientific plots, tables, 3D scenes and animations, with browser examples.
- Native and WASI execution, a browser playground and editor tooling.

## Compatibility and known limitations

- The interpreter remains the semantic reference. Native HIR/IR support is
  limited to tested source shapes; unsupported shapes are rejected or use a
  documented fallback.
- `Measurement<Quantity<D>>`, `Array<Measurement<T>>`, broader nested
  ownership combinations and general cancellation states remain guarded or
  unsupported.
- Effect and provenance coverage is incomplete. R3 remains open: the current
  evidence records partial effect capture and 4,266 unresolved effect calls.
- Numerical checks do not establish universal cross-platform equivalence or
  scientific correctness beyond their stated assumptions and tolerances.
- Linux ARM64, Intel macOS, musl and package-manager channels are outside the
  release matrix.
- Upstream GitHub Linguist recognition and a public package registry are not
  included.

## Examples

Try `examples/hello.ostrin`, `examples/measurement_phi.ostrin`,
`examples/native_dyn_trait_record_field.ostrin` and `examples/viz_table.ostrin`.
The gallery and Scientific Lab include plots, tables, 3D scenes and animations.

## Reporting problems

Open an issue at <https://github.com/sircalch/Ostrin/issues/new/choose>. Include
`ostrinc --version`, your operating system and architecture, a minimal program,
the command and its full output. For native compilation problems, include your
C compiler and its version.

See [`CHANGELOG.md`](../../CHANGELOG.md) for the detailed v0.2.0 history and
implementation scope.
