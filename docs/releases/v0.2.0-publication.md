## Reproduce download and checksum verification

From Linux or macOS:

```sh
gh release download v0.2.0 --repo sircalch/Ostrin --dir ostrin-v0.2.0
cd ostrin-v0.2.0
for file in *.tar.gz; do sha256sum --check "$file.sha256"; done
```

On Windows PowerShell:

```powershell
gh release download v0.2.0 --repo sircalch/Ostrin --dir ostrin-v0.2.0
Get-ChildItem ostrin-v0.2.0 -Filter *.zip.sha256 | ForEach-Object {
  $archive = $_.FullName -replace '\.sha256$', ''
  $expected = (Get-Content $_.FullName -Raw).Split(' ')[0]
  $actual = (Get-FileHash $archive -Algorithm SHA256).Hash.ToLowerInvariant()
  if ($actual -ne $expected) { throw "Checksum mismatch: $archive" }
}
```

Extract the platform archive, then run `ostrinc --version`, `ostrinc --check examples/hello.ostrin`, and `ostrinc --run examples/hello.ostrin`. The expected version is `ostrinc 0.2.0` and the example prints `hola desde Ostrin`. Install with `sh scripts/install.sh --version 0.2.0` on Linux/macOS or `scripts/install.ps1 -Version 0.2.0` on Windows. WASI users should verify the archive, extract it, then run `sha256sum --check SHA256SUMS` before invoking the compiler through a compatible WASI Preview 1 host.

## Compatibility and known limitations

Ostrin v0.2.0 is experimental; 0.x permits syntax, diagnostic and API changes. The interpreter remains the semantic reference, and native HIR/IR support is limited to tested source shapes. `Measurement<Quantity<D>>`, `Array<Measurement<T>>`, broader nested ownership combinations and general cancellation states remain guarded or unsupported. R3 provenance remains open, with 29 bundles and 4,266 unresolved effect calls. Numerical checks do not establish universal cross-platform equivalence. Upstream GitHub Linguist recognition has not been granted. Linux ARM64, Intel macOS, musl and package-manager channels are outside the release matrix. The release makes no claim of production readiness, universal memory safety, completed R3, or superiority over Python, Julia, MATLAB or Wolfram.
