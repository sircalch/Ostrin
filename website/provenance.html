Evidence boundary

Honest about what is missing.

The artifact is deliberately conservative. It is useful evidence for tooling and publication workflows, and it does not silently turn an effect inventory into a proof.

Available now

Source hashes are normalized across line endings, effect sites are serialized with stable paths, the target is explicit, and the report is available as text or JSON for native, WASI and browser tooling.

Next evidence layer

Input snapshots, output hashes, lockfiles, runtime metadata and platform tolerances will raise the report toward R2/R3 reproducibility. The design contract is documented in scientific effects and provenance ↗.
