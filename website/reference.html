Command line

ostrinc

The main flags. ostrinc --help lists all of them.

--check
Type-check (the default)
--run
Type-check and run
--test
Run every test_* function
--fmt
Print the formatted file (--write, --check)
--new
Create a project
--project
Use the entry declared by ostrin.toml
--locked
Require the existing ostrin.lock
--fetch
Fetch Git dependencies
--emit-c
Transpile to C
--compile
Build a native executable or WASI module
--target
native (default) or wasm32-wasi
--native-threads
OS threads and blocking channels
--leak-check
Report native allocations at exit
--hir
Print the typed, verified HIR
--ir
Print the basic-block IR
--ownership-check
Detect use after channel send (E1101)
--json
Machine-readable diagnostics
--lsp
Language server over stdio
--dap
Debug adapter over stdio
--version
Print the compiler version
