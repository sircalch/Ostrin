Measurement builds one new source list per operation and shares unchanged source records; it needed 450,008 allocations before the single-pass source merge and needs 200,010 now, with the same output and a peak of 12 live allocations. How to read this: the ratio is a measurement of Ostrin’s two execution modes, not a comparison with Python, Julia, Rust or another machine. Every workload also carries an output SHA-256 in the generated report, so a fast run that changes semantics is rejected. The historical index keeps prior commit records with their original environments.

Reproduce it

Source first. Numbers second.

Build the release compiler, run the deterministic workload set and regenerate the public data file. The raw JSON remains available as a CI artifact for each scheduled or manually triggered benchmark workflow.

cargo build --release --manifest-path compiler/Cargo.toml
node scripts/benchmark.mjs --iterations 7 --warmups 1
node scripts/benchmark-page.mjs --write
