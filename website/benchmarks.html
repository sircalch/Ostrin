Reproduce it

Source first. Numbers second.

Build the release compiler, run the deterministic workload set and regenerate the public data file. The raw JSON remains available as a CI artifact for each scheduled or manually triggered benchmark workflow.

cargo build --release --manifest-path compiler/Cargo.toml
node scripts/benchmark.mjs --iterations 7 --warmups 1
node scripts/benchmark-page.mjs --write
