Project guardrails

Technical focus keeps the community useful.

The repository has a code of conduct, a test-first contribution path and an honest roadmap. Community tooling should make those norms easier to follow, not pretend the project is larger than it is.

CONTRIBUTING

Evidence with every change

Relevant design decisions, positive and negative examples, tests, documentation and known limitations belong in a pull request.

CODE OF CONDUCT

Respectful disagreement

Critique ideas and code with patience, focus and evidence. Harassment, threats and deliberate disruption are not acceptable.
