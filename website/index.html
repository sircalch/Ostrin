The language

Three decisions
worth making explicit.

01

Dimensions are types

Lengths, times and derived quantities are checked before execution. A meter is not just a number with a comment beside it.

5 m + 2 s → error
02

Mutation is visible

Values are immutable by default. When state changes, the binding says so. That makes sharing and concurrency easier to reason about.

mut counter = 0
03

Errors have a shape

Option, Result and exhaustive match keep failure states in the model instead of hiding them in control flow.

try parse(input)
