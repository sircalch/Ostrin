Ostrin is a readable, statically typed programming language with physical quantities, explicit mutation and a safe-by-default concurrency model.

Why Ostrin?

Make important meaning visible in the code.

01

Physical quantities

Units are part of the type system. Incompatible dimensions are rejected before a program runs.

velocity = 10 m / 2 s
02

Safe concurrency

Immutable values can be shared. Mutable state is explicit and crosses task boundaries through channels.

task = spawn {
    process(data)
}
03

Readable syntax

Expressions, pattern matching and words such as and, or and try keep intent clear.

if temperature > 300 K and
   pressure > 1 atm {
    alert()
}
