01 / Quick start

Get a checked program running.

Ostrin currently builds with Rust and Cargo. Clone the repository, run the test suite and execute one of the examples through ostrinc.

PowerShell
# from the repository root
cd compiler
cargo test
cargo run -- --run ..\examples\physics.ostrin
cargo run -- --compile --native-threads ..\examples\concurrency_cancel_blocked_receive.ostrin
cargo run -- --compile --target wasm32-wasi ..\examples\hello.ostrin
Release status: Ostrin 0.1.0 is prepared as an experimental developer release for Linux x86_64, macOS arm64 and Windows x64. The v0.1.0 tag and GitHub release are not published yet; until then, build from source. The public package registry and GPU execution remain future work.

02 / Compiler workflow

One binary, several views.

The current command-line surface keeps the implementation inspectable. You can type-check a source file, run it, inspect AST/HIR/IR, emit editor symbols, publish type members, compile native code or emit structured diagnostics.

type-checkostrinc --check file.ostrin
editor diagnosticsostrinc --check --json file.ostrin
inspect HIRostrinc --hir file.ostrin
inspect IRostrinc --ir file.ostrin
check and runostrinc --run file.ostrin
native threadsostrinc --compile --native-threads file.ostrin
WASI targetostrinc --compile --target wasm32-wasi file.ostrin

What the checks are protecting

Quantities, mutation rules, generic bounds, trait behavior, pattern matching, modules, ownership cleanup, deterministic concurrency and native parity are all represented in tests and examples.

04 / Editor support

Ostrin in Visual Studio Code.

The repository includes the first extension surface. It recognizes .ostrin files, provides syntax highlighting, live diagnostics for unsaved text, a persistent stdio language-server session, type-aware member completion, signature help with active arguments, precise compiler-backed expression ranges and types in hover, definition navigation, workspace reference search for unique symbols, scoped rename, conservative document formatting, workspace-scoped semantic caching and an outline, and exposes commands to check or run the current file.

Install locally
cd vscode-ostrinnpx --yes @vscode/vsce packagecode --install-extension .\ostrin-language-support-0.2.0.vsix

After installation, VS Code detects every .ostrin file automatically. A local compiler build in compiler/target/debug is detected without extra configuration.
