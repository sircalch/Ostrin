01 / Quick start

Get a checked program running.

Ostrin currently builds with Rust and Cargo. Clone the repository, run the test suite and execute one of the examples through ostrinc.

PowerShell
# from the repository root
cd compiler
cargo test
cargo run -- --run ..\examples\physics.ostrin
Current expectation: this is a design-validation compiler. It is useful for exploring the semantics, but it is not yet a production application toolchain.

02 / Compiler workflow

One binary, several views.

The current command-line surface keeps the implementation inspectable. You can type-check a source file, run it, inspect an intermediate representation or emit structured diagnostics while the compiler grows.

type-checkostrinc --check file.ostrin
editor diagnosticsostrinc --check --json file.ostrin
check and runostrinc --run file.ostrin
inspect ASTostrinc --ast file.ostrin
inspect tokensostrinc --tokens file.ostrin

What the checks are protecting

Quantities, mutation rules, generic bounds, trait behavior, pattern matching, modules and the simulated concurrency model are all represented in tests and examples.

04 / Editor support

Ostrin in Visual Studio Code.

The repository includes the first extension surface. It recognizes .ostrin files, provides syntax highlighting and exposes commands to check or run the current file.

Install locally
code --install-extension vscode-ostrin
Next editor layer: a language server with source-aware diagnostics, type-aware completion, navigation and debugging support.
